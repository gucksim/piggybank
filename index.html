Облако не настроено. Вставьте конфигурацию Firebase в начало файла index.html (переменная window.FIREBASE_CONFIG), включите Authentication и Firestore и опубликуйте правила:

match /users/{uid} {
  allow read, write: if request.auth != null
                     && request.auth.uid == uid;
}

Войдите, чтобы сохранять данные в облаке и пользоваться ими на всех устройствах.
